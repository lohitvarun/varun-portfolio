# VARUN — THE PORTFOLIO

A cinematic, streaming-inspired personal portfolio for **Chevuru Lohit Varun Tej Reddy (Lohit Varun)**, a B.Tech CSE student specializing in AI & ML at Malla Reddy University, Hyderabad.

## Tech stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lenis smooth scrolling

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Portrait assets
The transparent portrait is stored as `pic.png`. Rebuild optimized WebP portrait assets and the social preview with:
```bash
npm run images
```

## Portfolio content
All editable portfolio information is centralized in `src/data/portfolio.ts`. Update the profile, education, experience, projects, achievements, certifications, skills, and journey there.

The supplied resume is available at `public/assets/Varun_Resume.pdf`. Replace it with a revised PDF when the resume changes.

## Notes
- Contact details and public profile links are sourced from the supplied resume.
- No home address, Aadhaar number, date of birth, or age is published in the portfolio.
- Project details are kept descriptive; no unverified performance metrics are displayed.
